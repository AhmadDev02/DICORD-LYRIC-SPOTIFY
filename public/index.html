⏱️ Cara Kerja Kecepatan & Jenis Lirik

⚡ 1. Lirik Presisi Real-Time (Synced LRC)

Ciri-ciri: Lagu populer (Spotify Premium, NetEase, LRCLIB Synced).

Cara Kerja: Lirik akan berganti 100% pas & presisi per detik mengikuti kata demi kata yang dinyanyikan penyanyi.

⏱️ 2. Lirik Teks Otomatis (Auto-Paced Text)

Ciri-ciri: Lagu indie atau lagu dengan lirik teks biasa tanpa stempel waktu.

Cara Kerja: Sistem membagi baris lirik secara merata sepanjang durasi lagu. Lirik berganti secara otomatis per 3–5 detik dari awal sampai akhir lagu.

⚙️ Tata Cara Konfigurasi Akun Discord & Spotify

  1. 1. Sambungkan Akun di Website: Pastikan Anda telah menyimpan Discord Token (Step 1) dan mengklik tombol Connect with Spotify (Step 2).
  2. 2. Buka Aplikasi Discord: Jalankan aplikasi Discord di PC atau Web Browser Anda.
  3. 3. Masuk ke User Settings: Klik ikon roda gigi ⚙️ User Settings di pojok kiri bawah samping nama profil Anda.
  4. 4. Buka Menu Connections: Pada panel menu sebelah kiri, gulir ke bawah dan klik menu Connections (Koneksi / Connected Apps).
  5. 5. Hubungkan Spotify ke Discord: Klik ikon Spotify, lalu ikuti petunjuk login untuk mengizinkan integrasi Discord dengan Spotify.
  6. 6. Aktifkan Tombol ON Status: Setelah terhubung, pastikan tombol "Display on profile" dan "Display Spotify as your status" diset ke posisi ON (Aktif).
  7. 7. Cek Status Profil Discord: Atur status Discord Anda menjadi Online 🟢, Idle 🌙, atau Do Not Disturb ⛔. (Catatan: Jika status diset ke Invisible ⚪ / Offline, lirik otomatis dipause untuk menjaga privasi Anda).
  8. 8. Putar Musik di Spotify: Buka aplikasi Spotify dan putar lagu favorit Anda.
  9. 9. Pantau Log di Web Dashboard: Buka kembali Web Dashboard ini untuk melihat log aktivitas lirik running ticker secara real-time!

📖 Panduan Cara Mengambil Discord User Token

  1. 1. Buka Discord di Web Browser Komputer

    Buka https://discord.com/app di Chrome, Edge, Brave, atau Firefox dan pastikan Anda sudah login ke akun Discord Anda.

  2. 2. Buka Developer Tools (Inspect Element)

    Tekan tombol keyboard F12 (atau Ctrl + Shift + I di Windows / Cmd + Option + I di Mac).

  3. 3. Buka Tab Network & Pilih "Fetch/XHR"

    Pada panel Developer Tools di sebelah kanan/bawah, klik tab menu Network, lalu klik tombol filter Fetch/XHR di bawahnya.

  4. 4. Filter & Ketik "@me"

    Pada kotak pencarian (Filter) di tab Network, ketik @me.

  5. 5. Refresh Halaman Web

    Tekan tombol F5 (atau Ctrl + R / Cmd + R) untuk merefresh halaman Discord, dengan syarat Developer Tools jangan ditutup.

  6. 6. Klik "{}" @me & Salin Kode "Authorization"

    Pilih baris berikon kurung kurawal {} @me (misalnya quests/@me) > pilih tab Headers > gulir ke bagian Request Headers. Salin seluruh kode acak di sebelah authorization:!
